### 🚀 Projetos em Destaque

#### 🍏 [CalorieSync — Aplicação Full Stack de Acompanhamento Nutricional](https://github.com/luiscorreiaa4/contador-de-calorias)
`React 19` • `TypeScript` • `Node.js` • `Express` • `PostgreSQL` • `TanStack Query v5` • `Zod` • `Vitest`
* Registro diário de refeições, cálculo automático de metas calóricas e de macronutrientes via **Taxa Metabólica Basal (TMB)** e gráficos interativos com Recharts.
* API RESTful em camadas utilizando driver PostgreSQL nativo (`pg`), 6 tabelas gerenciadas por migrações (`node-pg-migrate`) e **busca fonética/ortográfica de alimentos com índices GIN**.
* Autenticação JWT, hashing com `bcrypt`, validação com **Zod em 100% das rotas/DTOs**, segurança HTTP (`helmet`, `cors`, `express-rate-limit`) e **37 testes automatizados de backend** em banco isolado + testes de componentes no frontend com Vitest.

#### 🏆 [TFC — API de Gerenciamento de Campeonatos](https://github.com/luiscorreiaa4/TFC)
`Node.js` • `TypeScript` • `Express` • `MySQL` • `JWT` • `REST API`
* API RESTful para controle de partidas e classificação de torneios esportivos, com rotas privadas autenticadas via JWT, persistência relacional e cálculo dinâmico de tabelas de pontuação e desempenho.

#### 💼 [Nexus Consultoria — Plataforma de Gestão de Chamados e Serviços](https://github.com/luiscorreiaa4/Projeto3oPeriodo)
`Node.js` • `Express` • `EJS` • `PostgreSQL`
* Plataforma web para consultoria tecnológica com autenticação de usuários, gerenciamento de serviços/chamados e persistência relacional em PostgreSQL para administração de operações internas.
